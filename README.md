

Сайт: Training Library 
1. Как запускать сайт
1) Открыть папку проекта training_login
2) Найти файл index.html 
3) Открыть, выбрать браузер
Сайт сразу откроется в браузере

2. Структура проекта (Где что лежит)
Гитхаб:
• Папка Front: внутри все файлы html: index, index 2, catalog, login, python-course, python-purchase

• Папка styles: Внутри стили (файлы цсс)

Папка scripts: все скрипты

3. Что используется
• HTML5 — для разметки страниц
• CSS3 — для дизайна и адаптивности
• JavaScript — для интерактивности
