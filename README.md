

Сайт: Training Library 
1. Как запускать сайт
1) Открыть папку проекта training_login
2) Найти файл index.html 
3) Открыть, выбрать браузер
Сайт сразу откроется в браузере

2. Структура проекта (Где что лежит)
В корневой папке training_login лежат HTML-страницы:
• index.html — главная страница сайта
• index 2.html — вторая версия главной страницы (уже с входом в аккаунт)
• catalog.html — страница каталога всех курсов
• login.html — Страница входа и регистрации
• python-course.html — страница с подробным описанием курса Python
• python-purchase.html — страница оформления покупки/подписки на курс Python
Также в корне лежат две папки:
 
Папка style:
• style.css — основные стили сайта
• style 2.css — дополнительные или альтернативные стили
• catalog.css — стили specifically для страницы каталога 
• login.css — стили для страницы входа/регистрации 
• python-detail.css — стили для страниц с описанием курса Python
• responsive.css — адаптация сайта под экраны телефонов и планшетов
Папка scripts:
• script.js — основной скрипт 
• script2.js — дополнительный скрипт
• catalog.js — логика работы каталога 
• login.js — проверка правильности ввода пароля и почты на форме входа
• python-pages.js — скрипты для страниц курса Python 
3. Что используется
• HTML5 — для разметки страниц
• CSS3 — для дизайна и адаптивности
• JavaScript — для интерактивности
